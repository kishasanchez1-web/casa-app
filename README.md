## 🛠️ Rapid 5-Minute Onboarding Guide

This repository contains fully tokenized, production-ready interactive software frameworks engineered to run completely within 100% free-tier public cloud frameworks. Follow these steps to map these live assets to your unique brand path:

### Step 1: Push Repository to GitHub Profile
1. Create a free account on [GitHub](https://github.com).
2. Establish a public repository namespace named exactly `casa-app`.
3. Drag and drop the complete file manifest (`index.html`, `dispute.html`, `deploy_assets.py`) straight into your root repository path and commit changes.

### Step 2: Trigger Free Global Cloud Hosting Link
1. Click into your repository **Settings** tab (the gear configuration icon).
2. On the left sidebar menu under the automation grouping, select **Pages**.
3. Locate the **Build and deployment** module block, shift the deployment Branch selection dropdown list from *None* to **main**, and click **Save**.
4. Within 60 seconds, your applications will render completely live across public edge locations:
   - Flagship Life App: `https://github.io`
   - Automation Sandbox: `https://github.iodispute.html`
